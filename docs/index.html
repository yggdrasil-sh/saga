Alles an einem Ort

Saga verbindet ein Dashboard für deine Dienste mit einem persönlichen Notizbuch – ohne Cloud, ohne Abo, auf deinem eigenen Server.

🧭

Dashboard

Kacheln für alle Dienste mit Status-Punkten, Favoriten, Suche und Tastenkürzeln – optional mit eigener Websuche über SearXNG.

🔑

Zugang per Gruppe

Wer in s_nextcloud ist, sieht Nextcloud. Funktioniert mit lokalen Gruppen, LDAP und SSO gleichermaßen.

📝

Seiten im Notion-Stil

Blöcke, Unterseiten, Checklisten, Tabellen, Code, Bilder, Spalten, Vorlagen, Versionen und Markdown-Export.

🗂️

Datenbanken

Tabelle, Board, Liste, Galerie und Kalender – mit Filtern, Relationen, Berechnungen und Summen.

📅

Kalender & Aufgaben

CalDAV-Kalender (Nextcloud, mailcow, Radicale, iCloud) anzeigen und bearbeiten, Aufgaben mit Priorität und Wiederholung.

🔖

Eigene Lesezeichen

Jede Person legt ihre eigenen Kacheln an – privat, auch in den Apps sichtbar.

📷

Immich

Fotos aus der eigenen Immich-Bibliothek als Bilder und Titelbilder in Seiten verwenden.

👥

Mehrbenutzerfähig

Lokale Konten mit Registrierung, LDAP/Active Directory und Single Sign-On – Inhalte strikt getrennt.

🛡️

Admin-Bereich

Auf eigenem Port: Benutzer, Gruppen, Dienste, Registrierung, LDAP und SSO mit Verbindungstests.

Schreiben, planen, sammeln

Ein Notizbuch, das mitwächst – von der Einkaufsliste bis zur Projektplanung.

  • „/“-Menü für neue Blöcke, Verweise auf Seiten und Termine
  • Seitenbaum mit Unterseiten, Favoriten, Archiv und Papierkorb
  • Versionen – frühere Stände ansehen und wiederherstellen
  • Export als Markdown, auch mit allen Unterseiten

Datenbanken wie du sie brauchst

Eigenschaften anlegen, Ansicht wählen, fertig.

  • Ansichten: Tabelle, Board, Liste, Galerie, Kalender
  • Eigenschaften: Status, Auswahl, Datum, Zahl, Häkchen, Link, Relation, Berechnung
  • Filter, Sortierung und Summen je Ansicht

Für Admins gemacht

Eigener Admin-Bereich auf separatem Port – standardmäßig nur lokal erreichbar.

  • Benutzer anlegen, sperren, überall abmelden, Passwort setzen
  • Dienste mit Symbol, Kategorie und automatischer Zuweisung über die Gruppen-Kennung
  • LDAP/AD mit Vorlagen für FreeIPA, Active Directory und OpenLDAP
  • SSO/OIDC für Keycloak, Authentik, Authelia, Zitadel, Entra ID …

Screenshots

Apps für unterwegs und den Schreibtisch

Native Apps für iPhone, iPad, Mac, Linux (GNOME) und Android – keine eingebettete Webseite. Seiten, Datenbanken, Aufgaben und Termine werden direkt in der App angezeigt und bearbeitet. Anmelden geht mit der Serveradresse oder bequem per QR-Code aus „Apps & Geräte“.

In 5 Minuten starten

Du brauchst nur einen Server mit Docker.

# herunterladen
git clone https://github.com/yggdrasil-sh/saga.git && cd saga
cp .env.example .env
# BASE_URL, SECRET_KEY und POSTGRES_PASSWORD in der .env setzen
docker compose pull && docker compose up -d
# erstes Admin-Passwort anzeigen
docker compose logs saga | grep Admin-Konto

# später aktualisieren (vorher legt Saga automatisch ein Backup an)
git pull && docker compose pull && docker compose up -d
1 · Starten

Saga läuft auf Port 8080, der Admin-Bereich auf 8081 (nur lokal).

2 · Einrichten

Im Admin-Bereich Benutzer und Dienste anlegen, optional LDAP oder SSO verbinden.

3 · Loslegen

Mit HTTPS-Proxy davor freigeben – fertig ist dein eigenes Zuhause im Netz.
