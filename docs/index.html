Neu in Saga 2.3

Schneller mit vielen Daten, Föderation ohne Abstriche – und Backups, um die du dich nicht mehr kümmern musst.

0,6 sstatt 12 sbis eine Datenbank mit 2.000 Zeilen bedienbar ist
0,05 sstatt 1,0 sSeitenbaum neu laden bei 60.000 Seiten und Einträgen
1,3 sstatt 3,1 sbis der Seitenbaum bei 25.000 Notizen steht
−89 %2,5 → 0,28 GBDaten der App in 8 Stunden im Vordergrund

Gemessen mit der wiederholbaren Lastmessung tools/perf auf Testdaten.

⚡

Spürbar schneller

Antworten kommen komprimiert, der Seitenbaum gleicht nur noch Änderungen ab, lange Tabellen zeigen nur die sichtbaren Zeilen. Suche, Freigaben und Rückverweise rechnet der Server über vorbereitete Daten – gleiche Ergebnisse, nur schneller.

🌐

Föderation komplett

Personen verbundener Server über ihren Namen finden, Ende-zu-Ende-verschlüsselt chatten – direkt, in Gruppen und im Seiten-Chat – und telefonieren. Geteilte Seiten samt Datenbanken, Unterseiten, Uploads und Versionen gemeinsam bearbeiten. Nachrichtenanfragen und Sperren halten Unerwünschtes fern, jeder Server prüft alles selbst.

🗄️

Verschlüsselte Backups

Jeden Tag Datenbank, Dateien und Schlüssel nach S3, in einen Ordner oder auf Nextcloud/WebDAV – verschlüsselt mit age und deinem öffentlichen Schlüssel. Aufbewahrung 7/4/6, Prüfsummen, Benachrichtigung bei Fehlern, Testwiederherstellung und ein offenes Format, das sich auch ohne Saga entschlüsseln lässt.

☁️

Nextcloud-Dateien & persönliche Backups

Die eigene Nextcloud verknüpfen und Bilder, Dateien und Ordner als Block einfügen – wer die Seite sieht, sieht auch die Datei, ganz ohne eigenes Nextcloud-Konto. Und jede Person sichert ihren eigenen Workspace in ihre eigene Nextcloud, mit eigenem Schlüssel.

Datenschutz

Adressbuch, Chat und Anrufe lassen sich je verbundenem Server abschalten, und jede Person kann dem Adressbuch widersprechen.

Apps

Die Apps 2.3 erscheinen gleichzeitig – mit Föderation, Backups und Nextcloud-Dateien. Apps 2.1 laufen weiter, nur ohne diese Funktionen.

In 5 Minuten starten

Du brauchst nur einen Server mit Docker.

# herunterladen
git clone https://github.com/yggdrasil-sh/saga.git && cd saga
cp .env.example .env
# BASE_URL, SECRET_KEY und POSTGRES_PASSWORD in der .env setzen
docker compose pull && docker compose up -d
# erstes Admin-Passwort anzeigen
docker compose logs saga | grep Admin-Konto

# später aktualisieren (vorher legt Saga automatisch ein Backup an)
git pull && docker compose pull && docker compose up -d
1 · Starten

Saga läuft auf Port 8080, der Admin-Bereich auf 8081 (nur lokal).

2 · Einrichten

Im Admin-Bereich Benutzer und Dienste anlegen, optional LDAP oder SSO verbinden.

3 · Loslegen

Mit HTTPS-Proxy davor freigeben – fertig ist dein eigenes Zuhause im Netz.
