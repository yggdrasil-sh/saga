# Schriften der Projektseite

Lokal ausgeliefert (keine externen Schrift-Dienste), Untermengen aus den npm-Paketen
`@fontsource/fraunces` 5.3.0 und `@fontsource/noto-sans-runic` 5.3.0:

| Datei | Schrift | Schnitt | Zeichen |
|---|---|---|---|
| `fraunces-latin-600-normal.woff2` | Fraunces | 600 | latin |
| `fraunces-latin-ext-600-normal.woff2` | Fraunces | 600 | latin-ext |
| `fraunces-latin-400-italic.woff2` | Fraunces | 400 kursiv | latin |
| `fraunces-latin-ext-400-italic.woff2` | Fraunces | 400 kursiv | latin-ext |
| `noto-sans-runic-runic-400-normal.woff2` | Noto Sans Runic | 400 | Runen (U+16A0–16F8) |

Beide Schriften stehen unter der SIL Open Font License 1.1: `OFL-Fraunces.txt`, `OFL-NotoSansRunic.txt`.
Fraunces hat keine kyrillischen und thailändischen Zeichen – die russische und thailändische Seite fallen dort auf
System-Schriften zurück.
